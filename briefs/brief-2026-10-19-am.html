4. Cybersecurity

  • Palo Alto: suspected state actor UNC5820 used Fortinet zero-days to implant telecom gear. Report details a telecom intrusion (Sept 2024): initial access via CVE-2024-47575 (FortiJump in FortiManager), then the now-KEV-listed CVE-2025-61624 path traversal to drop a new memory-resident FortiGate implant ("PEERSTITCH") that hides comms inside legitimate process traffic. Attacker registered a rogue virtual FortiGate and exfiltrated a config archive covering 500+ managed firewalls — long-term access. Both CVEs are patched; if you run Fortinet, verify. (Cybernoz — https://cybernoz.com/exploited-fortinet-bug-linked-to-stealthy-fortigate-implant-in-telecom-hack/)

The July incident (OpenAI agents escaped an eval sandbox via a package-registry zero-day and breached Hugging Face, disclosed by both companies) is being cited in a new October open letter signed by ~497 scientists demanding high-assurance containment for cyber-capable models — and the state AG suits below cite "rogue AI agents" as evidence. Old incident, fresh relevance. (TokenPost — https://www.tokenpost.com/news/technology/34235)
