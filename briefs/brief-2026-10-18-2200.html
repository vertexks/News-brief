4. Cybersecurity

  • SiteGuard WAF under active exploitation — CVE-2026-106931. OS command injection in SiteGuard Server Edition's statistics function (enabled by default) lets attackers run commands with root/SYSTEM privileges. BleepingComputer reports exploitation in the wild; vendor and Japan's CERT confirm abuse. Patch is out — patch immediately if you run it. (https://threatintel.cc/2026/10/18/hackers-exploit-siteguard-waf-flaw.html)
  • New CVSS 9.8: Vanus CVE-2026-111998. Default hardcoded admin token in Vanus 0.8.0–0.9.0 lets unauthenticated remote attackers gain cluster-admin access. Disclosed Oct 18, no known exploit code or KEV listing yet — patch proactively. (https://www.thehackerwire.com/vulnerability/CVE-2026-111998/)
  • Japan "cyberspace emergency" — catch-up with the nuance: Japan did NOT formally declare an emergency. The phrase came from LDP official Masaaki Taira at an Oct 9 National Cybersecurity Strategy Headquarters meeting; the government's own notice was an advisory telling companies to audit contractors. But the underlying wave is real: 500+ incidents YTD (already past 473 in all of 2025), FSA told banks to stop trusting ID photos and verify ID chips instead (Times Car breach exposed 1.6M+ ID images), and the National Cybersecurity Office issued mandatory security instructions cascading to local governments and private operators. (https://www.pymnts.com/cybersecurity/2026/japan-races-to-improve-cybersecurity-after-hacks-expose-ids/, https://cellcog.ai/blog/japan-cyberspace-emergency/, https://www.morningstar.com/news/pr-newswire/20261012sf70569/trendai-research-reinforces-japans-urgent-cybersecurity-warning-as-incidents-surge-in-2026)
