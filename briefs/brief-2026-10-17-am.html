Ukraine — Russia's biggest anti-energy barrage in weeks overnight Oct 16–17. Zelensky called it one of the largest attacks on Ukraine's energy sector: 332 attack drones (31 jet-powered) + 4 Kalibr cruise missiles + Iskander-M/KN-23 ballistic and Kh-22/32 missiles. 2. Tech products (Apple / Nvidia / Google)

No major new announcements overnight. Follow-up: first independent reviews of Nvidia's RTX Spark laptops (on sale since Oct 16) are out. Verdict so far: strong real-world local inference and 128GB unified memory deliver, but the Arm Grace CPU + Prism emulation slows CPU-bound apps and games, sustained AI loads bring heat/noise and a 20–25% battery-performance penalty, and top 128GB configs run near $6,000.

Source: Particle review roundup (https://particle.news/story/nvidia-rtx-spark-laptops-launch-with-strong-local-ai-performance-and-clear-limits)

4. Cybersecurity

CISA added two more to KEV (Oct 17): Fortinet multiple-products path traversal CVE-2025-61624 and BeyondTrust Remote Support auth-bypass-by-spoofing CVE-2026-102764.

Source: SecurityAffairs via cybernoz (https://cybernoz.com/u-s-cisa-adds-fortinet-multiple-products-and-beyondtrust-remote-support-flaws-to-its-known-exploited-vulnerabilities-catalog/)

Threat actors are signing into 173 Microsoft 365 tenants with a compromised ConnectWise Cloud Backup credential. Campaign targets MSPs and their customers; audit sign-ins and rotate ConnectWise creds.

Source: The Hacker News via Cybersecurity Tracker (https://cybersecuritytracker.ai/)

Rank Math SEO PRO 3.0.123 shipped with malware in a limited distribution window (Oct 15–16). Wordfence: any site that downloaded and activated 3.0.123 should be treated as fully compromised (persistent backdoor, credential theft, hidden admin accounts). 3.0.124 is the clean replacement; restore from pre-incident backups.

Source: Wordfence via Cybersecurity Tracker (same link as above)

MALFEX supply-chain campaign: malicious npm package "imgdecode" hides a shellcode loader in a Windows native addon; 979 downloads and still live on npm. Avoid installing.

Source: Geek Guy digest (https://www.geek-guy.com/?v=28886f13f578)

New CVE-2026-110653 (CVSS 9.1): authentication bypass via race condition in WordPress Appointment Booking "LatePoint" plugin. Disclosed Oct 17; no public exploit confirmed yet — patch proactively.

Source: TheHackerWire (https://www.thehackerwire.com/vulnerability/CVE-2026-110653/)
