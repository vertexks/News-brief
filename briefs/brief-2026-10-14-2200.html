3. Open source

  • Petal (petal.live) — ex-CoScreen team shipped a free, open-source pair-programming and screen-sharing tool after Datadog sunset CoScreen in July; multi-user movable windows with labeled cursors, clickable typing/scrolling, persistent rooms, macOS/Windows/web via LiveKit, hosted or self-hosted. alobbs digest
  • Neckbeard — new DevOps/platform/SRE plugin for coding agents: analyzes the repo and emits reviewable cloud infrastructure + monthly cost estimates across AWS/GCP/Azure using tested OpenTofu modules, with GitHub Actions/GitLab CI and serverless-or-K8s support; installs into Claude Code and other SKILL.md-speaking agents. alobbs digest / github.com
