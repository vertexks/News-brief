OpenCode Console breached — attackers stole users' API keys for a "large-scale distillation attack"

Disclosed Oct 17–18: unauthorized access to a legacy system being decommissioned; 1.4% of Console users affected (only those with external providers linked). Victims report unauthorized charges of hundreds to $1,700; Anthropic/Google blocked the exposed keys, OpenAI is refunding. If you run OpenCode Console with linked provider keys, rotate them.
