PHP2Shell: emergency patches out today for two critical PHP flaws — NSA, FBI and CISA say patch now or take systems offline

PHP released fixes Wednesday (8.5.12, 8.4.27, 8.3.36, 8.2.35) for CVE-2026-109618 (RCE via out-of-memory corruption) and CVE-2026-109619 (RCE via stale global state), both CVSS 9.2, both allowing unauthenticated remote code execution. The release was pulled forward a day after details leaked on Hacker News ahead of the planned Oct. 22 disclosure. Apache mod_php is at highest risk — PHP says a demonstrated exploit triggers before application code runs — but FPM, CGI, FrankenPHP and LiteSpeed are also at risk. NSA, FBI and CISA urged immediate patching or taking unpatched systems offline; Unit 42 counts 22.6M+ internet-exposed instances potentially vulnerable. Cloudflare says it is already seeing early attack attempts and has deployed WAF rules; watchTowr honeypots logged exploitation attempts; several European government sites went offline to patch. CISA had not observed exploitation as of publication, and neither CVE is on KEV yet — but exploit code is circulating publicly, so this is a patch-now, not patch-soon, item.
